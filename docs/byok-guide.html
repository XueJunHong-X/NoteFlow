API Key 配置说明书

这份说明书只做一件事：帮你在 NoteFlow 里填好自己的 API Key，并确认它真的可用。 全文可以断网阅读，不依赖任何在线文档。

1

API Key 是什么

API Key 是你在多模态模型服务商那里生成的一串密钥。NoteFlow 用它调用你自己的模型接口， 把每一页笔记的图片交给模型识别成结构化文字。

本产品是纯 BYOK（Bring Your Own Key）。 NoteFlow 不提供账号、不代收费用、不经过任何中间服务器；你的请求从本机直接发往你填写的接口地址。

模型必须支持图片输入。只支持纯文本的对话模型不能用来识别手写笔记。

服务商通常只在创建时完整显示一次 Key，请当场复制并妥善保存；如果泄露，请到控制台删除并重新生成。

通义千问系列多模态模型，适合中文手写笔记识别。

控制台和接口地址要成对使用。 阿里云百炼每个地域有独立的 API Key 与接入地址，不能跨地域混用；上面的直达按钮默认打开华北2（北京）。 智谱的 Key 与接口地址也按上表对应，不要混填另一家的地址。

以阿里云百炼为例

  1. 打开控制台并登录
    访问 bailian.console.aliyun.com，用你的阿里云账号登录。
  2. 进入 API Key 页面
    在控制台左侧进入「API-KEY」，或直接打开 华北2（北京）API Key 页面。
  3. 创建并复制 Key
    点「创建 API Key」，按控制台提示确认归属账号、业务空间与权限，复制生成的字符串。它通常是一长串字母和数字，请完整复制，不要带多余空格。
  4. 确认模型已开通
    在模型广场确认你打算使用的多模态模型（例如 qwen-vl-max 或 qwen3-vl-plus）可用；首次使用可能需要按控制台提示开通模型服务。

智谱的流程类似：登录 智谱开放平台 → 进入 API Keys → 新建并复制 Key。

3

填到设置页

回到 NoteFlow，点主窗口右上角的「设置」，在「模型接口」卡片里填写三项：

设置 · NoteFlow
API Key 粘贴你刚复制的 Key
接口地址 https://dashscope.aliyuncs.com/compatible-mode/v1
模型名 qwen-vl-max
操作 测试连接  先测试，再保存
  • API Key：粘贴服务商给你的完整 Key。输入框默认打码，可勾选右侧「显示 Key」核对。
  • 接口地址：填上表里对应的地址；末尾不要多加 /chat/completions，NoteFlow 会自己拼接。
  • 模型名：填上表里对应的模型名，必须支持图片输入。
换服务商时三项要一起换。 只换 Key、不换接口地址和模型名，测试连接会失败。

找不到控制台地址时，随时回到设置页点「说明书」；这份文件就在程序的 docs 目录里，断网也能打开。

4

用「测试连接」确认可用

填好三项后，先不要急着保存。点「测试连接」——NoteFlow 会用当前填写的信息向接口发一次轻量请求， 只验证 Key、地址、模型名是否匹配，不会产生识别任务。

通过：连接正常（…） 失败：HTTP 401 · …
  • 显示「通过」：说明 Key 可用。再点「保存」，把配置和验证状态一起写入本机。
  • 显示「失败」：按下面的对照表排查，修改后重新点「测试连接」。
提示常见原因怎么改
HTTP 401 / 403 Key 不正确、已失效，或复制时缺了字符 回控制台重新复制或重新生成 Key，整段粘贴
HTTP 404 接口地址多了或少了路径，或模型名不存在 对照第 2 节表格，逐字核对接口地址与模型名
HTTP 400 模型不支持图片输入，或参数与该接口不兼容 换用支持视觉的多模态模型
连接超时 / 地址不可达 断网、代理或防火墙拦截 确认网络能访问该服务商域名后重试
HTTP 429 请求过于频繁，被服务商限流 稍等片刻再测；识别时把「识别并发」调成 1
Key 改动后，旧的「测试通过」会自动清空。 这是为了避免误以为新 Key 已经验证过——每次修改 Key，都需要重新点一次「测试连接」。
5

保存后，Key 以什么形式存在本机

点「保存」后，NoteFlow 会把配置写入当前 Windows 用户的应用数据目录：

%APPDATA%\NoteFlow\config.json

  • DPAPI 加密：API Key 使用 Windows DPAPI（CurrentUser 作用域）加密，文件里只保存 api_key_enc（加密后的密文）和 api_key_last4（末四位），没有明文 api_key 字段。
  • 只有本机当前用户能解开：把 config.json 拷到别的电脑或别的 Windows 账户，密文无法解密；换机后重新填一次 Key 即可。
  • 界面默认打码：设置页只显示末四位；需要核对时可临时勾选「显示 Key」。
  • 不会上传到别处：Key 只用于向你在「接口地址」里填写的服务商发起请求，NoteFlow 没有中转服务器，也不会把 Key 写进日志或安装包。
保存成功后你会看到「已加密保存到本机」的确认。 设置页会一直显示当前 Key 的状态：已验证 或 未验证。 重启 NoteFlow 后再次打开设置，状态仍然保留。

如果没有点过「测试连接」就直接保存，Key 仍会加密落盘，但状态会显示「未验证」； 建议补测一次，确认服务商返回「通过」。

6

没有 Key 时，哪些功能仍然可用

没有配置 Key 也能完整使用界面，只是不会调用真实模型。当前会明确显示为「离线示例」。

  • 离线演示：点主窗口的「离线演示」，用内置的合成样例图跑完整条链路——拆页、预处理、生成 Markdown、归档、索引与思维导图，全程不联网、不调用模型。
  • 查看产物：演示结束后可以打开笔记库，查看课程索引、笔记正文与 Mermaid 思维导图，确认输出结构符合预期。
  • 调整设置：路径、并发、清理等本机选项都可以先配置好，等拿到 Key 再切换真实识别。
离线示例不是真实识别。 它只用于演示链路和产物结构；处理你自己的手写笔记前，需要按第 2–4 节配置并验证 Key。

常见问题

我已经保存了 Key，为什么状态还是「未验证」？

保存只负责落盘，不会自动联网验证。请在设置页点一次「测试连接」，看到「通过」后再保存，状态才会变成「已验证」。

重启程序后，怎么确认 Key 还在、而且已验证？

打开「设置」，「模型接口」卡片里会显示当前 Key 的末四位和「已验证 / 未验证」。已验证状态会随配置保存在本机。

Key 会被 NoteFlow 收集或转发吗？

不会。Key 只保存在本机并直接用于你填写的接口地址；NoteFlow 没有账号体系、没有中转服务器，也没有任何代收或代理环节。

换一台电脑后为什么提示 Key 不可用？

API Key 使用 Windows DPAPI 按「当前用户」加密，密文只能在原账户下解密。换机或换账户后，在设置页重新填写并测试即可。

我只有纯文本模型的 Key，可以识别手写笔记吗？

不可以。识别需要把页面图片交给模型，必须使用支持图片输入的多模态模型，并按服务商表格填写对应的接口地址与模型名。
